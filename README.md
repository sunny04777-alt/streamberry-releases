# 젶라도와주는딸기 — 배포 저장소

제페토 라이브 방송 도우미 봇의 **배포본과 후원 아이템 정보**를 올려두는 곳입니다.
소스 코드는 여기 없습니다.

---

## 다운로드

최신 버전은 [Releases](../../releases/latest) 에서 받으세요.

봇을 이미 쓰고 있다면 **프로그램 안에서 알아서 알려줍니다.** 새 버전이 나오면
대시보드 위쪽에 안내가 뜨고, [지금 업데이트] 버튼 한 번이면 교체됩니다.
직접 받아서 덮어쓸 필요가 없습니다.

---

## 이 저장소의 파일

### `catalog.json`

봇이 주기적으로 읽어가는 파일 하나입니다. 두 가지가 들어 있습니다.

| 항목 | 내용 |
|---|---|
| `app` | 최신 버전 번호, 공지, 다운로드 주소, 체크섬 |
| `gift_item_id_map` | 후원 아이템 코드 ↔ 한글 이름 |
| `prices` | 아이템별 젬 가격 |

**사용자가 직접 정한 값이 항상 이깁니다.** 이 파일은 비어 있는 칸만 채웁니다.
직접 등록한 아이템 이름이나 가격을 덮어쓰지 않습니다.

네트워크가 안 되거나 이 파일에 문제가 있어도 봇은 평소대로 동작합니다.

---

## 후원 아이템 정보 제보

제페토는 새 후원 아이템을 자주 냅니다. 봇이 모르는 아이템은 `LIVE_WEBP_9` 같은
코드로 표시되고 가격도 0으로 잡힙니다.

**제보해주시면 다음 갱신 때 모든 사용자에게 반영됩니다.**

1. 대시보드 → 후원 아이템 설정 → **[내가 등록한 정보 내보내기]**
2. 복사된 내용을 디스코드에 붙여넣기

개인정보(팬 목록·VIP·포인트·계정 정보)는 담기지 않습니다. 아이템 이름과 가격뿐입니다.

## 버전 표기

릴리스 제목과 태그에 버전 번호를 씁니다.

```

v1.0.2   ← 릴리스 제목
```
